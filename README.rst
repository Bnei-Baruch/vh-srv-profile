*********
Endpoints
*********

Create profile
*******************

**PUT** `/v1/profile/create`

Header parameters
------------------
+-----------------+---------+----------------------------------------------------------------------------+
| Parameter       | Type    | Description                                                                |
+=================+=========+============================================================================+
| Content-Type    | string  | application/json                                                           |
+-----------------+---------+----------------------------------------------------------------------------+

Body
----

.. code-block::

    {
        "first_name": "",
        "last_name": "",
        "phone": "",
        "email": "",
        "password": "",
        "password_confirmation": "",
        "country": 1,
        "language": 1,
        "birthdate": "1980-01-01",
        "gender": 1
    }

+-----------------+---------+----------------------------------------------------------------------------+
| Content-Type    | string  | application/json                                                           |
+-----------------+---------+----------------------------------------------------------------------------+

Body
----

.. code-block::

    {

        "last_name": "",
        "phone": "",
        "email": "",
        "country": 1,
        "language": 1,

| Parameter       | Type    | Description                                                                |

| Token           | string  | Required. JWT token.                                                       |
+-----------------+---------+----------------------------------------------------------------------------+
| Content-Type    | string  | application/json                                                           |
+-----------------+---------+----------------------------------------------------------------------------+

Body
----

    {
        "email": ",

        "password": "",
        "password_confirmation": ""
    }
